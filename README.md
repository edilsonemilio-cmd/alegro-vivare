# Alegro Vivare — escala de plantões

Repositório: https://github.com/edilsonemilio-cmd/alegro-vivare

## Publicar na Cloudflare Pages

1. https://dash.cloudflare.com → Workers & Pages → Create → Pages → Connect to Git
2. Escolha o repositório **alegro-vivare**
3. Preset: None. Build vazio. Output: `/`
4. Deploy → sai `*.pages.dev`

## Imagens

Pela página do GitHub: Add file → Upload files → mande a pasta `img` (logo, casas, loja).
